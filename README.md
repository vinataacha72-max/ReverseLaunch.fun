Just open `index.html` in your browser.

## Deploy to GitHub Pages

1. Create a new repository on GitHub (example name: `launchonReverse` or `website`)
2. Push this code to the repository
3. Go to **Settings → Pages**
4. Source: Deploy from branch `main` / folder `/ (root)`
5. Your site will be live at `https://yourusername.github.io/reponame`

## Deploy to Vercel / Netlify (Recommended for custom domain)

1. Push to GitHub
2. Import the repo on [Vercel](https://vercel.com) or [Netlify](https://netlify.com)
3. Add custom domain: `launchonReverse.fun`
